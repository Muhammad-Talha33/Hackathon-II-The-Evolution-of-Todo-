   Service Port: {{ .Values.service.port }}

{{- if eq .Values.service.type "ClusterIP" }}

   The backend is only accessible within the cluster.

   To access from your local machine, use port-forward:

      kubectl port-forward svc/{{ include "backend.fullname" . }} 8000:{{ .Values.service.port }}

   Then access:
      - API:         http://localhost:8000
      - Health:      http://localhost:8000/health
      - API Docs:    http://localhost:8000/docs

{{- else if eq .Values.service.type "NodePort" }}

   Access the backend via NodePort:

      kubectl get svc {{ include "backend.fullname" . }} -o jsonpath='{.spec.ports[0].nodePort}'

   Then access:
      - http://localhost:<NodePort>
      - http://localhost:<NodePort>/health
      - http://localhost:<NodePort>/docs

{{- else if eq .Values.service.type "LoadBalancer" }}

   Get the external IP:

      kubectl get svc {{ include "backend.fullname" . }} -o jsonpath='{.status.loadBalancer.ingress[0].ip}'

   Once available, access:
      - http://<EXTERNAL-IP>:{{ .Values.service.port }}

{{- end }}
